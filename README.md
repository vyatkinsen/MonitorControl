# MonitorControl — яркость в быстрых настройках Windows 11

Управление аппаратной яркостью монитора **внутри системной панели Windows, над громкостью**. Расширение работает через переносимый Windhawk; отдельного окна и значка в трее нет.

- Внешние мониторы: DDC/CI, команда яркости VCP `0x10`.
- Встроенные экраны ноутбуков: WMI, если управление доступно в драйвере.
- Отдельный ползунок с названием и текущим процентом для каждого поддерживаемого экрана.
- При запуске, открытии панели и переподключении яркость только считывается.

Это расширение быстрых настроек, а не видеодрайвер и не регистрация внешнего монитора как встроенного ноутбучного экрана.

## Требования

Windows 11 x64 с быстрыми настройками в `ShellHost.exe`, [PowerShell 7.3 или новее](https://github.com/PowerShell/PowerShell/releases) (`pwsh`) для подготовки и сборки, интернет для загрузки Windhawk и символов Microsoft. В меню внешнего монитора должен быть включён DDC/CI; кабель и переходники должны передавать эти команды.

Администратор, служба Windows, отдельный видеодрайвер и .NET для этого варианта не требуются.

## Подготовка и запуск

Сохраните репозиторий в постоянную папку. Из PowerShell 7 в корне проекта выполните:

```powershell
.\Setup-Windhawk.ps1
.\Build.ps1
.\Install-Native.ps1
.\Set-Autostart.ps1
Start-Process .\tools\Windhawk\windhawk.exe -ArgumentList '-tray-only'
```

Подготовка загружает закреплённую версию Windhawk **1.7.3** с официального GitHub, проверяет SHA256 и подпись установщика и разворачивает переносимую копию в `tools/Windhawk`. Уже подготовленная копия повторно не устанавливается; работающий Windhawk не останавливается.

Откройте быстрые настройки через **Win+A** либо нажатием на область звука/сети возле часов. Яркость находится над громкостью. Движок ограничен процессом `ShellHost.exe`.

Установка создаёт локальные ярлыки **«Включить яркость в панели Windows»** и **«Отключить яркость в панели Windows»**. Отключение убирает добавленные ползунки; последняя аппаратная яркость сохраняется.

## Автозапуск

```powershell
.\Set-Autostart.ps1           # Включить после входа в Windows
.\Set-Autostart.ps1 -Disable  # Выключить автозапуск
```

Настройка действует только для текущей учётной записи: значение `MonitorControlNative` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Запускается `windhawk.exe -tray-only`, а его иконка скрыта настройкой проекта. Автозапуск не меняет яркость.

Если переносите папку, сначала выключите автозапуск и завершите расширение, затем включите автозапуск из новой папки. Отключение автозапуска само по себе не останавливает уже работающий экземпляр.

## Обновление и удаление

Перед заменой установленного модуля завершите свою переносимую копию:

```powershell
& .\tools\Windhawk\windhawk.exe -exit -wait -timeout 10000
.\Build.ps1
.\Install-Native.ps1
Start-Process .\tools\Windhawk\windhawk.exe -ArgumentList '-tray-only'
```

Для удаления выключите автозапуск, завершите расширение и удалите папку проекта. Системные файлы и видеодрайвер не заменяются.

## Проверка и ограничения

Проверенная конфигурация: **AQW34H3**, DisplayPort, **NVIDIA GeForce RTX 5070**, **Windows 11 26H2, 26300.9711**. Подтверждены появление ползунка в системной панели и видимое изменение яркости при его перемещении. Отдельный аппаратный тест подтвердил ответы на последовательность 58% → 59% → 58% с восстановлением исходного уровня.

Другие модели физически не проверялись. Поддержка зависит от DDC/CI или WMI; некоторые режимы HDR, KVM и док-станции ограничивают управление. Неоднозначные группы зеркальных экранов не управляются. Ползунок не измеряет яркость в нитах.

Модуль использует внутреннюю структуру панели Windows, поэтому после обновлений оболочки может потребоваться адаптация. Исходная версия проверена автором на Windows 11 25H2, сборка 26200; старые панели в `ShellExperienceHost.exe` не поддерживаются.

В Git не входят скачанные программы, готовые сборки, ярлыки с абсолютными путями, кеш символов, журналы и данные конкретного ПК. Зависимости восстанавливаются скриптом подготовки.
